# Definition of Done (DoD)

The **Definition of Done** is a shared understanding among the UniSphere team of what must be completed for a user story to be considered truly “done.”  
It applies to all tasks, features, and user stories in this project.

## Criteria

A user story is considered **Done** when:

- All **acceptance criteria** are met. 
- The code has been **merged into the shared repository** through a pull request.
- The work has been **peer reviewed** by at least one other team member.
- The feature has been **tested on all intended platforms** (e.g., browsers, devices).
- All **required documentation** has been completed or updated (e.g., comments, README, issue notes).
- The feature is **deployed or ready for deployment** to the shared environment. 

## Notes

- The Definition of Done should be **visible and agreed upon** by all team members.
- The team will **review and refine** the DoD periodically to ensure it remains relevant.
