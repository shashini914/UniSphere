## Project Description

On university and college campuses, students often struggle to stay updated on events, club activities, and important deadlines because this information is scattered across multiple platforms. Posters, Instagram stories, email chains, and word-of-mouth announcements create fragmented communication, making it difficult for students to keep track of everything happening on campus. As a result, many students miss valuable opportunities to participate in activities that match their interests. Similarly, student clubs face challenges reaching their target audiences and efficiently managing event promotion. There is currently no unified digital platform that brings all campus activities together in an organized and accessible way.

Our project, UniSphere, addresses this challenge by creating a centralized Campus Event & Club Management Portal. UniSphere serves as a one-stop hub where student clubs can post and manage their events, while students can easily browse upcoming activities, RSVP to events, and follow clubs they’re interested in. The portal features a user-friendly event listing page, club profiles, and a calendar view that displays all upcoming events in an organized format. Club administrators can log in to create, edit, or delete events, ensuring information is always accurate and up to date. By consolidating campus activities into a single platform, UniSphere enhances student engagement, streamlines event promotion for clubs, and strengthens the overall sense of community on campus.

UniSphere will be developed using React for the front end to build a dynamic, responsive, and modern user interface. The back end will be powered by Flask (Python) to handle server-side logic, authentication, and API endpoints. For data storage, we will use SQLite or PostgreSQL, which will manage information about users, clubs, and events efficiently. GitHub will be used for version control and collaboration through branches, pull requests, and issues. This technology stack allows for clear task division between front-end, back-end, and database development, supporting a smooth and organized workflow throughout the project lifecycle.
